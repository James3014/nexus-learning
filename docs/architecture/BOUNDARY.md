# Nexus Learning Architecture Boundary

## Lifecycle Contract
1. Ingest verified outcome evidence only.
2. Form content-addressed learning episode.
3. Compute effectiveness and coverage.
4. Output bounded recommendation.
5. Provide independent validation & rollback schemas.

## Authority Invariants
- Learning recommendations are NOT execution authority.
- No direct route mutation allowed.
- No direct CapabilityPlanner mutation allowed.
- No workforce admission mutation allowed.
- No model self-promotion allowed.
